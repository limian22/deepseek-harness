# 子级模型策略约束每次委派

[English](guide.md) | 中文

## 变更

此前，子智能体模型选择列表只约束显式模型参数。省略参数时，子级可能继承列表外的父模型。现在，Session 已记录的策略同时约束普通、fork、工作流及直接服务委派。省略选择时，优先使用列表内生效的配置路由，其次是列表内的父路由，否则使用策略第一项。显式指定未授权路由时直接拒绝，不会重定向。无法选择子级 LLM 路由的后端，包括固定模型的 Codex、Claude Code 和 ACP 集成，在 Session 策略生效时拒绝委派。

没有已记录策略的 Session 保留原有默认行为。设置修改仍仅影响新的顶层 Session；已有策略在恢复后继续生效。本次变更不改写会话历史。

## 迁移

1. 在子智能体设置中检查授权模型列表，纳入新子级委派可能使用的所有模型；若所有可选择路由的子级都应使用 Flash，则只选择 Flash。
2. 如果部署通过 `agentOptions` 或 `agentRouteDefaults` 提供子级默认值，请把其生效的提供方／模型组合纳入列表以保留默认值。否则，省略选择时会解析为其他授权路由。
3. 若需使用 Harness 无法选择模型的后端，请关闭模型选择，并创建没有已记录策略的新顶层 Session。关闭设置不会移除现有 Session 中已经记录的策略。
4. 加载更新后的运行时后，不指定模型参数创建子级，并检查其记录的提供方／模型。它必须属于 Session 的授权列表；显式指定列表外路由必须在子级启动前失败。
